# 🎯 目标检测功能说明

## ✅ 功能实现

根据您的要求，系统现在实现了真正的目标检测功能：

### 核心特性
1. **智能检测**: 使用YOLOv8检测画面中的物体
2. **精准分类**: 使用ResNext101对检测到的物体进行垃圾分类
3. **条件显示**: 
   - ✅ 检测到垃圾物体 + 置信度 ≥ 30% → 显示边界框和标签
   - ❌ 没有检测到物体 → 不显示任何框
   - ❌ 置信度 < 30% → 不显示框

## 🔄 工作流程

```
输入图像/视频帧
    ↓
YOLOv8目标检测 (检测画面中的所有物体)
    ↓
对每个检测到的物体:
    ↓
    裁剪物体区域
    ↓
    ResNext101分类 (判断是否为40类垃圾之一)
    ↓
    置信度 ≥ 30%?
    ↓
    是 → 显示边界框 + 中文标签 + 置信度
    否 → 不显示
```

## ⚙️ 技术架构

### 两阶段检测
1. **第一阶段 - YOLOv8目标检测**
   - 模型: YOLOv8n (nano版本，速度快)
   - 功能: 检测画面中的所有物体
   - 输出: 物体边界框坐标

2. **第二阶段 - ResNext101分类**
   - 模型: 训练好的ResNext101
   - 功能: 对检测到的物体进行垃圾分类
   - 输出: 40个类别之一 + 置信度

### 置信度阈值
- **默认值**: 30% (0.3)
- **含义**: 只有分类置信度 ≥ 30% 时才显示检测框
- **调整方法**: 修改 `conf_threshold` 参数
  ```python
  detector = GarbageDetector(
      model_path=model_path,
      class_names=class_names,
      device=device,
      conf_threshold=0.5  # 改为50%，更严格
  )
  ```

### 边界框颜色
- 🟢 **绿色**: 置信度 > 80% (高可信度)
- 🟠 **橙色**: 置信度 60-80% (中等可信度)
- 🔴 **红色**: 置信度 30-60% (低可信度)

## 📝 注意事项

### 1. YOLOv8首次运行
- 首次运行会自动下载YOLOv8n模型 (约6.2MB)
- 下载后会缓存，后续运行无需重新下载

### 2. 检测性能
- **GPU (RTX 4060)**: 
  - 图像检测: 100-200ms
  - 视频检测: 实时 (30fps)
- **CPU**: 
  - 图像检测: 500-1000ms
  - 视频检测: 较慢 (10-15fps)

### 3. 检测准确率
- **YOLOv8**: 通用物体检测，准确率高
- **ResNext101**: 垃圾分类，平均准确率77%
- **组合效果**: 先检测后分类，整体准确率取决于两者

### 4. 置信度阈值选择
- **30%**: 平衡检测率和误检率（推荐）
- **50%**: 减少误检，但可能漏检
- **20%**: 增加检测率，但误检增多
