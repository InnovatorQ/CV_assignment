## 📊 工作原理

### 两阶段检测流程

```
┌─────────────────────────────────────────────────────────┐
│                     输入图像/视频帧                      │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│              第一阶段: YOLOv8目标检测                    │
│         检测画面中的所有物体（通用物体检测）             │
└─────────────────────────────────────────────────────────┘
                            ↓
                    检测到物体？
                    ↙        ↘
                 是            否
                 ↓             ↓
┌──────────────────────┐   ┌──────────────────────┐
│ 第二阶段: 分类每个物体│   │   不显示任何框       │
│                      │   └──────────────────────┘
│ 对每个检测到的物体:   │
│ 1. 裁剪物体区域      │
│ 2. ResNext101分类    │
│ 3. 判断置信度        │
└──────────────────────┘
         ↓
    置信度 ≥ 30%？
    ↙        ↘
  是            否
  ↓             ↓
┌──────────┐  ┌──────────┐
│ 显示框   │  │ 不显示框 │
│ + 标签   │  └──────────┘
│ + 置信度 │
└──────────┘
```

## ⚙️ 参数配置

### 置信度阈值调整

在 `main.py` 或 `demo.py` 中修改：

```python
detector = GarbageDetector(
    model_path=model_path,
    class_names=class_names,
    device=device,
    conf_threshold=0.3  # 默认30%
)
```

**推荐值**:
- **0.2 (20%)**: 检测更多物体，但可能有误检
- **0.3 (30%)**: 平衡检测率和准确率（推荐）
- **0.5 (50%)**: 只显示高置信度检测，减少误检
- **0.8 (80%)**: 非常严格，只显示极高置信度

### 边界框颜色含义

| 颜色 | 置信度 | 含义 |
|------|--------|------|
| 🟢 绿色 | > 80% | 高置信度，分类结果非常可靠 |
| 🟠 橙色 | 60-80% | 中等置信度，分类结果基本可信 |
| 🔴 红色 | 30-60% | 低置信度，建议人工确认 |

## 💡 使用技巧

### 1. 提高检测准确率
- ✅ 确保光照充足
- ✅ 物体清晰可见
- ✅ 避免严重遮挡
- ✅ 合适的拍摄距离

### 2. 处理低置信度结果
如果检测结果置信度较低：
- 重新拍摄（更好的角度/光照）
- 降低置信度阈值（如改为20%）
- 人工确认分类结果

### 3. 批量处理图像
创建脚本 `batch_detect.py`:
```python
import os
from utils.detector import GarbageDetector
import config
import torch

# 初始化检测器
detector = GarbageDetector(
    model_path='models/best_resnext_model.pth',
    class_names=config.CLASS_NAMES,
    device='cuda',
    conf_threshold=0.3
)

# 批量检测
image_dir = 'path/to/images'
for img_file in os.listdir(image_dir):
    if img_file.endswith(('.jpg', '.png')):
        img_path = os.path.join(image_dir, img_file)
        save_path = os.path.join('results', f'detected_{img_file}')
        
        image, detections, _ = detector.detect_image(img_path, save_path)
        
        if detections:
            print(f"{img_file}: 检测到 {len(detections)} 个物体")
        else:
            print(f"{img_file}: 未检测到垃圾")
```

## 🐛 故障排除

### 问题1: YOLOv8下载失败
**症状**: 提示无法下载yolov8n.pt

**解决方案**:
1. 检查网络连接
2. 手动下载: https://github.com/ultralytics/assets/releases/download/v8.3.0/yolov8n.pt
3. 放到项目根目录

### 问题2: 检测不到物体
**症状**: 总是显示"未检测到垃圾物体"

**解决方案**:
1. 降低置信度阈值（改为0.2）
2. 确保图像清晰
3. 检查物体是否在画面中

### 问题3: 检测速度慢
**症状**: 处理速度很慢

**解决方案**:
1. 确认使用GPU（应显示"cuda"）
2. 降低检测频率（改为每10帧）
3. 使用更小的图像分辨率

### 问题4: 中文显示异常
**症状**: 中文标签显示为方块或乱码

**解决方案**:
1. 确认Windows字体存在: `C:\Windows\Fonts\msyh.ttc`
2. 重新安装Pillow: `pip install --upgrade Pillow`
